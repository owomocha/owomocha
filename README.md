I'm a security engineer working on reverse engineering and systems software, mainly in Rust, C and Python. I examine the behavior of binaries and communication protocols, using system performance analysis to identify bottlenecks and guide low-level optimization.

For financial and market data, I use market microstructure to inform time-series models built on stochastic processes. In signal extraction and alternative data analysis, I account for sampling bias and nonstationarity, examining the assumptions behind statistical inference and the uncertainty of estimates.

In distributed systems, including blockchains, I examine the security assumptions of cryptographic protocols alongside event ordering and state consistency. I try to distinguish assumptions from observations, checking reproducibility and the limits of interpretation as I revise my understanding.

セキュリティエンジニアとして、リバースエンジニアリングとシステムソフトウェアの開発に取り組んでいます。バイナリや通信プロトコルの挙動を読み解き、システム性能解析を通じてボトルネックの特定と低レイヤー最適化を進めています。主に Rust・C・Python を使っています。

金融・マーケットデータでは、マーケットマイクロストラクチャを手がかりに、確率過程に基づく時系列モデリングを行っています。シグナル抽出やオルタナティブデータの分析では、標本の偏りや非定常性を考慮し、統計的推論の前提と推定の不確実性を検討しています。

ブロックチェーンを含む分散システムでは、暗号プロトコルの安全性の前提と、イベントの順序・状態の整合性を実装の側から検討しています。仮定と観測を分け、再現性と解釈の限界を確かめながら、理解を更新するようにしています。
